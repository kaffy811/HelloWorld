## 股票图表

Real-Time / 5D / 1M / 3M / 6M / 1Y；Trend / Candles；历史区间可按 Daily / Weekly / Monthly 聚合。鼠标滚轮缩放、拖拽平移、起止滑块、缩放/重置按钮和键盘操作均有入口。十字线展示时间、OHLC、基准变化和成交量；最近十条数据也可用表格查看。

Real-Time 是 IEX 常规交易时段分钟图，在页签可见时每60秒检查一次；不是逐笔 WebSocket 推送或全美市场行情。5D使用最近五个实际交易时段的15分钟数据，含当日已出现的数据；遇到无成交的分钟不造数据。未开市时保留最后有数据的时段并显示日期。长区间使用已缓存的完整日线，尚未完成的当日日线不混入历史特征。

后台 `/api/stocks/[ticker]/chart` 仅接受六个已有代码及live/5d，密钥只留服务端。Supabase共享缓存TTL分别60/300秒；数据库租约合并并发刷新，防止每个访客重复请求同一图表。来源失败保留旧缓存并标注stale，首次失败显示切换日线的提示。

## Notebook 三类用途

- **Term explanations**：专业词解释与来源。当前可保存文章已有AI术语讲解或编辑词库解释；两种来源清楚标注。文章中选中已解释的精确词语可打开解释弹层并保存。新选取词语的即时AI生成留待下轮，未匹配时明确提示，不伪造解释。此前句子收藏保留为历史片段，无新增整句收藏入口。
- **AI conversations**：登录用户自己的问题、AI摘要、原始完整答案入口、继续追问和Markdown下载。生成提示仍保存；自己的问答按20条分页。曾标记factual_error的回答摘要不继续当作可信知识展示。
- **My notes**：自己的见解/学习笔记，标题+正文，私有创建与修改，Markdown下载，归档/恢复。编辑版本校验避免另一页签的改动被静默覆盖；浏览器关闭提醒保留未保存草稿。没有自动将笔记发送给AI。

独立新表personal_notes使用自身用户RLS读/写，不能冒用他人ID或访问他人笔记。下载也验证所有者，无公开分享。

## Learn 与评分

Learn保留，新增每天轮换的三条编辑词库建议。已保存的词库主题与能精确匹配的AI词语会排除，相关主题优先。当前只使用本地词库关系与纽约日期，明确标注编辑内容，不是假称AI推荐。九个词库主题可进入完整阅读页。

AI新闻/私人问答与词库文章均支持五级 usefulness 评分：1 😕 Not useful / 2 🤔 Still unclear / 3 🙂 Somewhat useful / 4 💡 Useful / 5 🤩 Very useful。选择后确认保存；每用户/内容一个记录，可以更新。初次投票INSERT、后续UPDATE，数据库分数范围/对象/所有者检查。低分可附原因。评价学习帮助程度，不评价股价会涨还是跌。词库评分清楚标注为编辑解释评价。

content_feedback 保存新五级评分；此前二元ratings历史不改写，AI详情可展示历史统计。私人内容不可被他人读取或评分。
