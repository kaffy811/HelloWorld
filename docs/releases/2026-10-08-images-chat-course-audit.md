# 图片笔记、AI 助手、学习反馈与课程验收

## 本轮功能

1. Notebook / My notes 支持最多三张图片。PNG、JPEG、WebP，每张上传最多 2 MB；服务端解码、旋转、缩至最长边 1600，再编码为 WebP 并移除原始元数据。文件保存在私有 notebook-images 桶，数据库存所有者、SHA256、尺寸及状态。只有本人可以读、附到笔记或用于聊天。移除附件是解除关联，不会销毁历史生成使用的图片。
2. 右下角机器人进入 `/assistant`，不绑定某篇文章，支持日常问题及股票知识。打开页面只读取历史，不自动消耗生成额度；发出问题才调用 Gemini。当前没有联网搜索，不能保证回答最新事实；截图中的财务数值视为用户提供的未验证资料。
3. 通用聊天与文章聊天都可附一张图片，暂不接受 PDF、Word 等文件。界面标明发送后图片会交给 Google Gemini。提示词只保存图片 ID、哈希、尺寸等元数据，发送时从本人私有存储读取并校验字节。生成结果、实际提示词、图片引用、模型与 usage 保存在既有生成流水和回答表，图片变化参与缓存身份。收藏聊天、重新打开及 Markdown 导出保留图片引用。
4. 每篇每日 AI 学习文章保留五级 Emoji 评分，并增加私密文字反馈（最多 1000 字）和可选风格偏好：更简单、多举例、更深入、关联知识。首次保存插入 ai_lesson_comments，后续可修改；只能评价本人生成的学习文章。
5. 每天纽约日期变更后，用户第一次访问 Learn 才生成五篇；本次读取最近评分、反馈、Notebook，确定选题与风格。当天再次访问复用缓存，反馈不会偷偷重写已经评分的文章。评论在服务端提取允许的风格标签，原始评论不送给模型。这是每日访问触发的自适应生成，不是无人访问时也运行的后台定时任务。
6. 系统默认 English，新用户数据库字段默认 en。已明确选择中文的用户保留选择。语言设置在 Profile 中；导航删除 Settings，旧 `/settings` 兼容重定向到 `/profile#language`。历史保存文章保留原语言并标记版本，新 AI 回答使用系统语言。
7. 财报可选中专业词汇与表格标题。13 个双语常见术语优先走内置词典，即时、没有模型调用；可以保存到 Notebook，明确标为 Learning library，不伪称 AI 生成。复杂或未覆盖的文本继续使用上下文 AI。比如 Operating income / Income statement 已在真实浏览器测试。

图片上限：每人滚动 24 小时最多上传 20 张，当前保留最多 100 张（含尚未完成的记录）；限制在数据库租约中原子执行。聊天仍复用共享免费 AI 额度，不新增付费服务。[Gemini 官方图片请求格式](https://ai.google.dev/gemini-api/docs/generate-content/image-understanding)。

## 数据库与可复现性

- 本轮迁移 `202610080006_images_assistant_comments.sql` 已在 hello-world-db 应用成功，不要重复执行。
- 新增 user_images、ai_lesson_comments，personal_notes 新增 image_ids；所有图片引用通过数据库触发器校验所有权。新表 RLS 默认拒绝匿名，写生成记录及图片元数据仅服务端；用户可写自己的笔记与学习评论。
- 生产检查：25 张 public 应用表，0 张未开启 RLS；notebook-images public=false，允许格式 WebP，存储单文件上限 1,500,000 字节。跨用户图片、评论、评分及伪造附件的隔离场景已通过。
- 通用助手提示词版本 `us-assistant-v1`；文章阅读仍为 `us-reader-v9`。JSON 导出保存实际提示词与图片哈希，可以对照私有原图复现；playback 不再次调用模型。数值来源严格校验继续适用于文章解释，通用助手单独校验语言、长度和禁止伪造引用，不把普通日常答案错误套入财报数字校验。
- 每日偏好按当前反馈生成并写入当天实际提示词。模型具有随机性，不能承诺每次重新生成文字完全相同；缓存及导出回放可以精确重现已保存版本。

## 提交前复现流程

1. 额度恢复后，先在 Profile 确认 English。点机器人，上传普通公开截图，提问，确认回答识别图片且保存生成记录；点收藏聊天，再从 Notebook 打开。
2. 展开某个真实 AI 回答的 ＋，提交 Emoji，刷新确认分数保留。在每日文章写反馈，下一天新生成的提示词中检查 learning_preferences；同一天仍保留旧批次。
3. Notebook 新笔记添加图片、保存、刷新。登出后同一图片 URL 应返回 401，另一用户不能读取。
4. 发布本轮代码到 Vercel，确认同一生产 Supabase 和 Gemini 服务端配置，按具体部署 URL 测试登录回调与图片。
5. 核对部署保护并使用无登录窗口访问特定提交的部署 URL，记录 Git 提交 SHA 和部署 URL；最后在课程提交页面提交。不要把 API 密钥或用户私有记录放入提交材料。
