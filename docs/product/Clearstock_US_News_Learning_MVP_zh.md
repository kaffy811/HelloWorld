# Clearstock 美股新闻学习 MVP

日期：2026-10-07（America/New_York）

## 产品决定

服务美股入门用户：把公司公告与股票知识解释清楚，帮助用户逐步理解业务、市场信息和交易基础。保留既有 Clearstock 登录、个人资料和学习偏好。所有本轮代码位于 HelloWorld 仓库对应的 humor-app；独立 HumorProject 不受影响。

全站今日页和个股新闻页共用已保存的分析，用户打开即可阅读。没有初次生成按钮、幽默内容、买卖分数或价格预测。上传资料和追问属于登录后的主动学习。

## 已实现页面

| 路径 | 内容与交互 |
|---|---|
| `/` | 美股学习入口、公司/主题搜索、公司更新与社区学习、六家现有公司 |
| `/stocks/[ticker]` | 业务介绍、学习问题、关注按钮、最新公司解读、真实行情缺失状态 |
| `/stocks/[ticker]/news` | 同一公司已发布的 SEC 解读 |
| `/news/[id]` | 摘要、事实、影响路径、潜在有利因素/压力、未知项、术语、来源、评分、私人追问 |
| `/watchlist` | 私人自选与关注公司的解读 |
| `/learn` | 股票、营收利润、利润率、价格与价值、市价单、限价单的基础说明 |
| `/materials` | 公开文本/截图生成学习卡片；列出本人的卡片和追问 |
| `/notebook` | 原有学习入口保留，连接新的学习集合 |

公开新闻分析以英文共享；用户资料生成与追问支持英文、简体中文。现有十项语言偏好仍保留，但本轮不声称十种语言都已支持生成。

已实现搜索仅覆盖当前公司列表和最近 30 条已发布分析；没有宣称全量历史搜索。当前资讯为公司官方申报，行业/宏观分类与来源扩充列入下一阶段。

## 数据与生成流程

后台按公司 CIK 获取 SEC submissions，选择近 30 天内最新的 8-K、10-Q、10-K，每家最多处理两份。获取文件正文，去掉 HTML/隐藏 XBRL 区域，截取可控大小的文本；来源明确标注这是摘录，可能缺少后续章节和附件。

Company Facts 作为补充，只选择证据截止时间以前申报的全年 USD 营收、净利润；校验 10-K、FY、起止日期和持续期间。未找到可比事实时明确缺失。当前不提取完整季度/分部指标，不尝试计算 PE 或目标价。

证据包：公司业务介绍＋公告摘录＋可用全年事实＋数据限制。没有授权行情时，明确禁止模型推断股价与成交量。

每次生成记录完整系统指令、用户输入、结构 schema、模型、参数、提示版本；图片记录清洗后文件路径、MIME 和哈希，不把图片 base64 塞进数据库。文件在私有 Storage 保存。

模型输出经过结构、引用 ID、事实/影响部分数字检查后，用数据库函数原子保存分析与完成状态。数字检查不能证明引用确实支持语义；本轮还需要上线后的人工抽查。不是全自动准确性认证。

同一已完成输入直接返回已有结果，不重新调用模型。数据库串行预留全局每日额度，失败尝试仍计数；用户每日最多三次、间隔至少一分钟，相同失败输入最多尝试两次。日期额度与 Gemini 的日额度重置按美国太平洋时间，页面内容时间显示美东时间。

后台会把超过 15 分钟的未完成预留标成中断，允许有界重试。失败的私人上传记录/原文件可能仍保留；保留期限和自动清理列入后续运营工作。

## 评分与发布

💡 Helpful / 😕 Not helpful。负反馈可补充术语太多、过长、公司关联不清楚、问题未回答、疑似事实错误。

每位正式登录用户对每个分析版本插入一票，数据库主键防重复。用户不能更新/删除票数、冒用他人身份或修改生成结果。公开计数通过过滤可访问分析的窄范围函数汇总，不公开 voter ID。统计失败时显示暂不可用，不显示伪造的零票。

用户学习卡片默认私有，可以主动发布已确认来自公开资料的学习卡片。发布会公开解释及文本证据，原图和完整生成提示仍私有。追问始终私有，并使用原分析的证据截止时间和证据包；本轮不把先前模型输出作为事实证据。

## 上传范围

- 公开新闻/公告短文本：10–12,000 字符。
- 公开表格/文章截图：JPEG、PNG、WebP，不超过 2 MB。
- 服务端实际解码图片，限制像素、尺寸，重新编码为 WebP，并剥离元数据。
- 只讲解截图可见概念，不把无法核实的数值当作已确认事实。
- 暂不接收 PDF、持仓、账户、流水或身份资料。
- 简单检测部分敏感文本，不承诺全面识别图片或文本里的个人信息。用户必须确认资料公开且不含个人信息。

## 安全边界

新增所有 public 表启用 RLS。既有 companies/profiles 的 RLS 保留。公开访问只读已发布分析及对应新闻；私人生成记录、上传、投票和自选按本人身份过滤。客户端没有原始新闻、提示、上传元数据、生成结果的写权限。服务端生成函数仅 service_role 可调用。

Storage learning-materials 私有，只允许用户读取本人已登记路径；客户端不能任意写入该 bucket。发布学习卡片通过限定的本人发布函数执行。

所有写接口检查用户身份和请求 Origin，拒绝匿名 Auth 用户。OAuth 完成后返回原页面，首次资料引导期间通过短期 HttpOnly Cookie 保存允许范围内的返回路径。

## 零预算与本轮限制

方案面向小规模非商业课程演示。SEC 数据读取不收费；免费 AI/托管的账号资格、额度和数据条款仍需由部署者确认，不能保证长期无限零成本。环境开关只是应用配置，并不能验证云账户是否连接付费计费。

当前没有公开展示授权的行情，价格模块显示缺失。Finnhub、Alpha Vantage 的免费调用不等于公开分发许可；本轮没有接入它们，也没有 Yahoo/yfinance 爬取。没有为留存承诺全市场实时新闻。

GitHub Actions 每日两次 UTC 时间采集，可能延迟，不能作为实时系统。需配置仓库 secrets/vars 才能运行。

第一版数据库每条 SEC 事件关联一个申报公司。跨公司行业事件、多个关联影响版本、宏观来源、美联储/BLS 接入和后续修订链属于 P1，届时扩展关联表；不将尚未实现内容写成已上线。

## 验收与下一阶段

已完成：生产构建与类型检查、lint、既有 onboarding 测试、新增七项数据/生成测试、隔离 PostgreSQL 的十五项迁移/RLS 场景。PGlite 模拟 auth/storage 接口，不替代真实 Supabase Auth、Storage、OAuth 与 AI 提供方的端到端验证。

上线前必须在实际环境验证：Google 登录与返回、两名用户的私有资料隔离、一次真实上传、一次真实 AI 生成及提示下载、公开发布和另一名用户评分、重复票拒绝、首轮 SEC 同步，以及具体部署 URL 的无痕访问。

P1 优先：完整新闻附件/财报章节定位、行业与宏观事件关联、多公司影响分析、固定质量数据集、人工复核和反馈面板、理解题实测、文件保留与删除流程。实时行情需要先获得适用授权。
